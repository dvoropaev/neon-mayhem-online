# Неоновый хаос — русская версия

Коста-Роса, 1986 год. Открытый мир с гонками, погонями, сюжетными заданиями, магазинами, транспортом и радио. Переведены меню, диалоги, задания, обучение, игровые сообщения, названия, вывески, радио и газета.

## Запуск

Распакуйте архив и запустите из его папки любой сервер статических файлов. Например, если установлен Python:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000` в современном браузере. Нажмите Enter или коснитесь экрана, чтобы начать. На телефоне удобнее играть в горизонтальной ориентации.

## Управление

WASD — движение, мышь — обзор, левая кнопка мыши — огонь, F — сесть в транспорт или взаимодействовать, пробел — прыжок или ручной тормоз, Shift — бег, L — помощь Лолы, P — карта, Esc — пауза.

Полная памятка для клавиатуры, геймпада и сенсорного экрана: [Управление](docs/CONTROLS.md). Клавиши можно переназначить в меню паузы. Буквы клавиш соответствуют физическим клавишам латинской раскладки.

## Сохранения

Прогресс сохраняется в браузере. В меню паузы можно экспортировать сохранение в файл и импортировать его обратно. Формат сохранений совместим с исходной версией игры. Для сохранений на прежнем адресе используйте тот же браузер и адрес сервера.
